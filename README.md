# Splitlist — support

Support and privacy for **Splitlist**, a shared to-do list app. Friends join a
list, add tasks, and check them off.

This repository exists so that Splitlist has a public place to receive bug
reports and questions, and a public home for its privacy policy. The app's own
source code is not here.

## Get help

- **[Open a support request](https://github.com/6dzzx4zb7h-afk/splitlist-support/issues/new/choose)**
- **[Browse existing issues](https://github.com/6dzzx4zb7h-afk/splitlist-support/issues)** — your question may already be answered

This tracker is public. Please do not post your password, and avoid screenshots
showing other people's names, email addresses or list contents.
